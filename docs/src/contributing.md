# Contributing

Read [CONTRIBUTING.md](https://github.com/Busnes-app/KyDrive-for-Android/blob/main/CONTRIBUTING.md)
for setup, security requirements and the pull-request process. The
[suite contribution policy](https://github.com/Busnes-app/.github/blob/main/CONTRIBUTING.md)
also applies. Major functionality includes automated tests; warnings are fixed or
documented as false positives.

Report ordinary bugs and proposed enhancements in
[Issues](https://github.com/Busnes-app/KyDrive-for-Android/issues). Include reproducible
steps and environment details. Discuss a major feature before implementation so its
scope and server/API dependencies can be assessed. Documentation, small fixes and test
improvements can be proposed directly.

Send vulnerabilities privately using
[SECURITY.md](https://github.com/Busnes-app/KyDrive-for-Android/blob/main/SECURITY.md).
Public bug reports are not the place to publish a working credential or exploit against
someone's deployment.

## Keep this book current

Edit Markdown under `docs/src/`; register new chapters in `SUMMARY.md`. Keep current
UI labels and implemented workflows aligned with source. Put plans in `docs/DESIGN.md`
and clearly distinguish them from instructions for available features.

Build with mdBook and run the generated-link checker before submitting. Commit the
sources and configuration; generated `docs/book/` is a review artifact. Screenshots
must come from disposable test systems and must not contain real account data.
